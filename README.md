# BlurTalk

BlurTalk is a mini full-stack backend project built as my attempt to understand how backend systems actually work.

Just one week before building this, concepts like servers, databases, authentication, and request handling were mostly theoretical to me. This project represents my hands-on effort to understand how **Node.js, Express, and MongoDB** work together to power real applications.

This is not a production-ready social platform.  
It is a learning milestone.

---

## 🚀 Why I Built This

I built BlurTalk to deeply understand:

- How a backend server works
- How Express handles routing and middleware
- How MongoDB stores and retrieves data
- How authentication works using JWT and cookies
- How users and posts relate in a database
- How like/unlike logic works internally
- How server-side rendering works using EJS

Instead of only watching tutorials, I wanted to build something that forced me to debug real problems and connect all the pieces myself.

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS (Server-side rendering)
- JWT (Authentication)
- Cookie-parser
- Bcrypt

---

## ✨ Current Features

- User Registration
- User Login / Authentication
- Create Posts
- Like / Unlike Posts
- Protected Routes
- Basic User-Post Relationship Handling

---

## ⚠️ What This Project Does NOT Include (Yet)

BlurTalk is intentionally simple. It does NOT currently include:

- Email verification
- Password reset system
- User search functionality
- Profile image uploads
- Real-time updates (AJAX/WebSockets)
- Notifications
- Advanced security hardening
- Production deployment setup

Apps like Twitter or Meta products include these features, but this project focuses on understanding backend fundamentals first.
